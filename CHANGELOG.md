# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-12-01

### Added

- **Monorepo setup** with Turborepo, npm workspaces, and shared TypeScript config
- **Next.js 15 frontend** with React 19, Tailwind CSS 4, and shadcn/ui components
- **NestJS 11 backend** with modular architecture, JWT auth, and Swagger docs
- **PostgreSQL 16** database with Prisma ORM schema, migrations, and seed data
- **Redis 7** integration for caching and session management
- **AI Engine** with FastAPI, scikit-learn for dynamic pricing and demand forecasting
- **Docker Compose** setup for full-stack local development and production deployment
- **CI/CD pipeline** with GitHub Actions (lint, type-check, build, test)
- **Authentication system** with Argon2 hashing, JWT tokens, and role-based access
- **Property management** module with room types, floors, and amenities
- **Reservation system** with real-time availability and booking engine
- **Guest management** with profiles, preferences, and communication history
- **Billing & invoicing** with automated calculations and Stripe integration
- **Analytics dashboard** with occupancy, revenue, and performance KPIs
- **Housekeeping module** with task assignment and status tracking
- **Role-based access control** for admin, manager, front-desk, and housekeeping roles
- **Comprehensive documentation** — README, Contributing guide, Security policy, Code of Conduct
- **GitHub templates** for issues and pull requests
